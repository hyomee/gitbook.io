# 개방형 프로토콜

A2A와 MCP의 차이점

| 특징          | A2A (Agent-to-Agent) 프로토콜                                                                                                                                                           | MCP (Model Context Protocol)                                                                                                                                                        |
| ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **주요 목표**   | **에이전트 간의 협업 및 통신**. 서로 다른 에이전트들이 복잡한 작업을 함께 해결하도록 돕는 공통 언어 역할을 합니다.                                                                                                                | **AI 모델이 외부 도구를 사용하는 방법 표준화**. 외부 데이터, 애플리케이션, 서비스와 통신할 수 있는 표준화된 '언어'를 제공합니다.                                                                                                      |
| **역할 비유**   | 팀원들과 소통하고 조율하는 **"프로젝트 매니저"**.                                                                                                                                                      | 필요한 도구를 사용하는 **"전문 기술자"**.                                                                                                                                                          |
| **상호작용 대상** | 다른 **AI 에이전트**.                                                                                                                                                                     | 외부 **툴(도구), API, 데이터베이스** 등.                                                                                                                                                        |
| **작동 방식**   | 에이전트들이 서로를 발견하고, 역량을 파악하며, 메시지를 주고받아 복합적인 워크플로를 처리합니다.                                                                                                                              | AI 모델이 외부 도구의 기능과 매개변수를 이해하고, 필요에 따라 해당 도구를 호출합니다.                                                                                                                                  |
| **데이터 처리**  | 에이전트 간에 **상태를 공유하고 멀티모달 메시지를 교환**하는 무거운 구조를 가질 수 있습니다.                                                                                                                              | 비교적 경량 프로토콜로, 필요한 **최소한의 규약**만 정해져 있습니다.                                                                                                                                            |
| **핵심 기능**   | **자율 에이전트 간의 상호 운용성**을 높입니다.                                                                                                                                                        | **AI 모델이 실시간 데이터에 접근하고 실제 행동**을 할 수 있게 합니다.                                                                                                                                         |
| **상호 관계**   | 상호 보완적 관계. A2A가 없는 MCP는 고립된 에이전트를 만들고, MCP가 없는 A2A는 도구를 사용할 줄 모르는 에이전트를 만들 수 있습니다.                                                                                                  | 상호 보완적 관계. A2A가 없는 MCP는 고립된 에이전트를 만들고, MCP가 없는 A2A는 도구를 사용할 줄 모르는 에이전트를 만들 수 있습니다.                                                                                                  |
| **예시**      | <p><strong>A2A:</strong> 여행 계획 에이전트, 예약 에이전트, 결제 에이전트가 협력해 여행 일정 전체를 자동화.<br><strong>MCP:</strong> 하나의 에이전트가 MCP를 통해 Flight API를 사용해 항공편을 조회하거나, Google Maps API를 사용해 길을 찾는 기능.</p> | <p><strong>A2A:</strong> 여행 계획 에이전트, 예약 에이전트, 결제 에이전트가 협력해 여행 일정 전체를 자동화.<br><strong>MCP:</strong> 하나의 에이전트가 MCP를 통해 Flight API를 사용해 항공편을 조회하거나, Google Maps API를 사용해 길을 찾는 기능.</p> |

요약한마디로 정리하자면, **MCP는 AI에게 도구를 사용하는 능력을 부여**하는 반면, **A2A는 AI에게 다른 AI와 협업하는 능력을 부여**합니다. MCP를 통해 에이전트가 외부 세계와 상호작용하는 능력을 얻고, A2A를 통해 이렇게 능력 있는 에이전트들이 서로 협력하여 더 복잡한 문제를 해결할 수 있습니다.
