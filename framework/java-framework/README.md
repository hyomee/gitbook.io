# Java Framework

## LLM 및 생성형 AI 관련 프레임워크

* **Spring AI**: 스프링 프레임워크(Spring Framework) 기반의 AI 애플리케이션 개발을 위한 프레임워크입니다.
  * **특징**: 기존 스프링 생태계에 익숙한 자바 개발자들이 쉽게 AI 기능을 통합할 수 있도록 설계되었습니다.
  * **주요 기능**: LLM(대규모 언어 모델), 멀티모달(텍스트, 이미지, 음성 등), 함수 호출, RAG(검색 증강 생성) 등을 지원합니다.
  * **강점**: 벤더 중립적이어서 여러 LLM(ChatGPT, Claude 등)에 연결할 수 있습니다.
* **Embabel**: 스프링 프레임워크 창시자 중 한 명인 로드 존슨이 만든 오픈소스 프로젝트입니다.
  * **특징**: 자바 기반 애플리케이션에 안전하고 유연한 AI 에이전트 워크플로우를 통합하는 데 중점을 둡니다.&#x20;

## 딥러닝 프레임워크

* **Deeplearning4j (DL4J)**: 자바 가상 머신(JVM) 기반 딥러닝 라이브러리입니다.
  * **특징**: Restricted Boltzmann machine, deep belief net, word2vec 등 다양한 딥러닝 알고리즘을 지원하며, 분산형 딥러닝 기능을 제공합니다.
* **Deep Java Library (DJL)**: 아마존(Amazon)이 개발한 오픈소스, 엔진에 독립적인 딥러닝 프레임워크입니다.
  * **특징**: 텐서플로, 파이토치 등 다양한 딥러닝 엔진을 백엔드로 사용할 수 있으며, 자바 개발자에게 친숙한 API를 제공합니다.
* **Neuroph**: 자바로 작성된 객체 지향 인공신경망 프레임워크입니다.
  * **특징**: 가벼운 프레임워크로, 일반적인 신경망 아키텍처를 구축하고 훈련하는 데 사용됩니다.&#x20;

## 머신러닝 및 데이터 처리 라이브러리

* **Apache Mahout**: 하둡(Hadoop) 및 스파크(Spark)를 기반으로 확장 가능한 머신러닝을 지원합니다.
  * **특징**: 추천 시스템, 분류, 클러스터링 등에 강점이 있습니다.
* **WEKA**: 데이터 분석 및 머신러닝을 위한 자바 라이브러리이자 GUI(그래픽 사용자 인터페이스) 기반 도구입니다.
  * **특징**: 데이터 전처리, 분류, 회귀, 클러스터링 등 다양한 기능을 제공하며, 교육용으로도 많이 사용됩니다.
* **Smile**: 자바 개발자를 위한 빠르고 확장 가능한 통계 머신 인텔리전스 및 학습 엔진입니다.
  * **특징**: 지도 및 비지도 학습 알고리즘, 자연어 처리(NLP), 데이터 시각화 도구를 포함합니다.
* **Java-ML**: 다양한 머신러닝 알고리즘을 포함하는 자바 머신러닝 라이브러리입니다
