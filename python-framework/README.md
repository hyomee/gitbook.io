# Python Framework

## CrewAI, AutoGen, AWS Strands Agents, LangChain 비교

| 특징           | CrewAI                                        | AutoGen                                             | AWS Strands Agents                                        | LangChain                                              |
| ------------ | --------------------------------------------- | --------------------------------------------------- | --------------------------------------------------------- | ------------------------------------------------------ |
| **핵심 철학**    | 역할 기반 협업. 명확한 역할, 목표, 배경을 가진 에이전트들의 구조화된 팀워크. | 대화 기반 협업. 에이전트 간의 자동화된 채팅을 통해 복잡한 작업을 동적으로 해결.      | 모델 중심 접근 방식. 복잡한 워크플로 대신 AI 모델 자체의 계획 및 도구 사용 능력을 활용.     | LLM 기반 애플리케이션 개발 도구 모음. 에이전트는 LangChain의 여러 컴포넌트 중 하나. |
| **에이전트 협업**  | 명확한 역할과 순서 또는 계층적 프로세스를 통해 팀워크를 수행.           | 에이전트 간의 유연하고 동적인 대화(채팅)를 통해 워크플로를 진행.               | 모델 기반의 의사결정으로 에이전트 간의 상호 작용을 최적화.                         | 에이전트 자체의 협업 기능은 제한적이며, LangGraph를 통해 복잡한 상호 작용 구현.     |
| **워크플로**     | 순차적 또는 계층적 프로세스로 구현되며, 역할 기반으로 자동화에 최적화.      | 대화 기반의 동적이고 유연한 워크플로.                               | 모델 기반의 자동화된 추론을 통해 워크플로를 처리.                              | 체인(Chains), 툴킷(Toolkits) 등 다양한 컴포넌트를 사용하여 워크플로 구축.     |
| **사용 편의성**   | 직관적이고 설정이 쉬워 신속한 프로토타입 개발에 적합.                | 유연하지만, 복잡한 문제 해결을 위한 워크플로 설계에 더 많은 초기 노력이 필요할 수 있음. | 모델 중심 접근 방식으로 에이전트 구축이 간편. AWS 서비스와의 통합에 최적화.             | 모듈식 구성으로 유연하지만, 높은 학습 곡선이 필요할 수 있음.                    |
| **주요 활용 사례** | 콘텐츠 마케팅, 여행 계획 등 역할이 명확하고 구조화된 작업.            | 복잡한 코드 개발, 데이터 분석 등 유연한 해결책이 필요한 연구 및 개발.           | AWS 환경에서의 AI 에이전트 개발 및 배포. 특히 아마존 Q, AWS 글루 등 내부 서비스에 활용. | 챗봇, RAG(검색 증강 생성), 데이터 분석 등 다양한 LLM 기반 애플리케이션 개발.      |
| **장점**       | 쉬운 설정, 역할 기반의 구조화된 협업, 빠른 프로토타입 개발.           | 유연한 대화 기반의 협업, 풍부한 커뮤니티 지원.                         | 모델 중심 접근 방식으로 간편한 개발, AWS 서비스와의 긴밀한 통합.                   | 모듈식 구성, 다양한 컴포넌트 통합, 높은 유연성.                           |
| **단점**       | 복잡한 작업에서 워크플로가 예상과 다르게 동작할 수 있음.              | 복잡한 워크플로 설정 시 더 많은 노력이 필요할 수 있음.                    | AWS 환경에 대한 의존성.                                           | 복잡한 설정, 높은 학습 곡선.                                      |
| **적합한 사용자**  | 명확한 팀 기반 작업을 빠르게 자동화하려는 개발자.                  | 에이전트의 유연한 상호 작용을 탐구하고 복잡한 문제를 해결하려는 연구자 및 개발자.      | AWS 인프라에서 안정적인 프로덕션 수준의 AI 에이전트를 구축하려는 개발자.               | 폭넓은 LLM 기반 애플리케이션을 개발하고, 다양한 컴포넌트를 유연하게 조합하려는 개발자.     |
