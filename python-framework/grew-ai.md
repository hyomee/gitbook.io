# Grew AI

각 에이전트에게 역할, 목표, 배경을 부여해 마치 잘 조직된 인간 팀처럼 작동하도록 설계되었습니다. 주요 구성 요소&#x20;

* **에이전트(Agents):** 특정 역할과 전문성을 가진 가상의 팀원입니다. 스스로 의사 결정을 내리고, 필요하면 외부 도구를 사용해 작업합니다.
* **작업(Tasks):** 에이전트에게 할당되는 잘 정의된 단위 작업입니다. 명확한 목표와 기대 결과물이 포함됩니다.
* **크루(Crews):** 특정 프로젝트나 목표를 달성하기 위해 모인 에이전트들의 그룹입니다. 작업 분배와 조정을 관리합니다.
* **프로세스(Process):** 에이전트들이 협력하는 방식을 정의하는 워크플로 관리 시스템입니다.
  * **순차적(Sequential):** 릴레이 경주처럼 각 에이전트가 순서대로 작업을 완료합니다.
  * **계층적(Hierarchical):** 프로젝트 매니저 역할을 하는 에이전트가 다른 에이전트들의 작업과 소통을 관리합니다.&#x20;

***

CrewAI의 특징

* **역할 기반 아키텍처:** 에이전트에 명확한 역할과 목표를 부여하여 작업 충돌을 줄이고 효율성을 높입니다.
* **유연한 통합:** 다양한 LLM 제공업체 및 도구와 쉽게 통합할 수 있습니다.
* **손쉬운 사용:** 복잡한 멀티 에이전트 시스템을 쉽게 설정하고 프로토타입을 만들 수 있어, 초보자도 빠르게 시작할 수 있습니다.
* **확장성:** 작은 규모의 크루부터 시작해 필요에 따라 더 많은 에이전트를 추가하여 복잡한 워크플로를 관리할 수 있습니다.
* **독립적인 프레임워크:** LangChain과 같은 다른 에이전트 프레임워크에 의존하지 않고 처음부터 자체적으로 개발되었습니다.&#x20;

***

활용 예시

* **콘텐츠 마케팅:** 시장 조사, 데이터 분석, 콘텐츠 작성, 편집 등 여러 에이전트가 협력하여 전체 마케팅 캠페인을 기획하고 실행합니다.
* **여행 계획:** 개인별 맞춤 여행 일정을 짜는 데 여러 에이전트가 협력합니다.
* **채용:** 구인 공고 작성, 이력서 검토, 후보자 평가 등을 자동화하는 데 사용될 수 있습니다.
* **재무 분석:** SEC 데이터 통합을 포함한 재무 분석을 수행하는 에이전트 팀을 구성할 수 있습니다
